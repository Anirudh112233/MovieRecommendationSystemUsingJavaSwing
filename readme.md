# 🎬 Movie Recommendation System

A **feature-rich desktop application** built using **Java Swing** to provide users with an engaging and personalized movie discovery experience. The system offers a wide range of recommendations tailored to user preferences, moods, and trending topics.

## ⭐ Features
- **Personalized Recommendations**: Suggests movies based on user preferences and watch history.
- **Trending Recommendations**: Highlights popular and trending movies.
- **Mood-Based Recommendations**: Curated lists to match specific moods (e.g., happy, adventurous, relaxing).
- **Exploring Hidden Gems**: Recommends underrated and lesser-known movies.
- **Watchlist Sharing**: Allows users to create and share their watchlists with friends.
- **Documentary Suggestions**: Recommends insightful and trending documentaries.
- **Curated Watchlists**: Provides customized watchlists for specific moods and themes.

## 🖥️ Technology Stack
- **Programming Language**: Java
- **Framework**: Java Swing
- **IDE Used**: NetBeans
- **Data Storage**: Local file storage (expandable to a database).

## 📥 Installation and Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/movie-recommendation-system.git```
2. Open the project in your Java IDE (e.g., NetBeans, Eclipse, IntelliJ).
3. Compile and run the `Main` class to start the application.

## ⚙️ How It Works
- Users can browse or search for movie recommendations tailored to their preferences.
- The system features mood-based and curated watchlists for specific themes.
- Users can explore hidden gems or discover trending and popular movies.
- A watchlist feature allows users to save and share their favorite movies.
